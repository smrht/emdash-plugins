Backlinksbeheer Link Check

Check outbound links from saved EmDash entries with [Backlinksbeheer](https://backlinksbeheer.nl). No account or API key required.

Choose a content collection and saved entry, inspect its links, then check up to two links per step. Every observation includes the HTTP status and measurement time. A one-minute pause applies before contacting the same host again.

- HTTP 2xx: reachable. - HTTP 3xx: redirect observed; destination shown, not followed. - HTTP 404 or 410: missing at the time checked, not proof of permanent removal. - HTTP 403, 429, server errors and timeouts: unknown.

Reads saved Portable Text links and static HTML anchors. Ignores scripts, same-site links, email links and private IP literals. HEAD first, with one GET fallback for servers that reject HEAD. At most 200 distinct outbound links per entry; a warning appears when content exceeds the inspection limits.

Requires EmDash 1.1+ and a plugin sandbox. Permissions: content:read, schema:read and unrestricted network requests. Only linked URLs go to their destination websites; entry text is not uploaded to Backlinksbeheer. Reports stay in the site's plugin storage. The private admin page requires plugin-management permission.

No link edits, redirects, background crawling or account synchronization. The latest report is shared by site administrators. This complements account-based backlink monitoring on Backlinksbeheer.

[Source and full instructions](https://github.com/smrht/emdash-plugins/tree/main/packages/backlinksbeheer-links).
